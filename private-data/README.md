# 私有题面备份

parts与backup-parts.json保存38道候选题面、PDF、页图和原始清单的认证加密分片备份。63个分片按清单合并后的密文为3969444字节。inventory.json 给出解密后23个文件的相对路径、长度和SHA-256。题面为第三方候选，来源登记未构成公开再分发许可。

密钥分开保存在用户交付目录。密钥不进入Git、PR、项目ZIP或日志。恢复只在本地解密到.private/math-reference。请同时备份密文与密钥，丢失密钥无法恢复。

此仓库保持私有。授权状态不明的原文不得从解密目录公开发布。需要清除备份时采用正常Git历史清理流程，删除当前文件不会移除历史密文。
