# 全国数学真题扩容

此目录为全国数据的公开元数据、来源归属与研究层。完整第三方题面、答案、原PDF/TeX与图片保存在相对路径.private/national-reference，通过独立密钥恢复。原有38题仍从既有数据库只读适配，ID、原始文件与备份不变。

当前新增21卷、458条题目实例、449条唯一主记录；9条同内容跨卷实例共享主记录。2023乙卷理科23条因实质转写错误整卷隔离，默认不用于研究和命题。其余435条仍是待逐题核实的完整候选，不是官方认证试题或已验证答案。总库含旧38题为23份数学卷、496条实例、487条唯一主记录。

用卷关系与考试制度分开：2024河南数学使用新课标Ⅰ卷，同卷只存一次，但河南该年仍为旧3+x；2020旧全国Ⅰ文理卷与新高考Ⅰ卷是不同系列。2020—2022部分过渡课标待核，不按省份改革年份强行认定。

详细恢复、查询、导入见仓库README的第五阶段说明。catalog/question-registry不含完整题面，必须恢复私有数据后才能查询全文。来源许可及底层权利界限见upstream-notices；共享结构不等于取得原题的额外再分发许可。
