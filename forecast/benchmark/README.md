# 命题特征盲标基准 v2

[固定规则](rubric.json)按数学对象、题面任务和必要推理划分特征。每个标签保存适用域、正例、相似负例和证据要求。证据不清的适用题保留未知。多个标签可以共存。当前估计不改变原有 v1 回测和 2027 冻结预测。

## 独立评测

从严格复核档案按卷抽样。随机层使用固定种子和稳定排序。定向层加入难辨的正负例。按试卷、共享主记录和已识别的改编相似群切分。公开候选包含规则和评测程序。私有试题正文、图片和盲标原始材料从维护者的研究包本地读取。

```sh
python scripts/feature_benchmark.py predict feature-blind.json new-predictions.json
python scripts/feature_benchmark.py evaluate feature-blind.json feature-key.json reviewer-a.json reviewer-b.json adjudicated.json new-predictions.json new-benchmark.json
```

输入题面含匿名 ID、适用题型、题干、选项、子问和图像元数据。输出为逐题逐标签的 1、0、未知及证据。自动提议为保守规则，可弃权。评测验证题面、索引、规则和自动输出哈希。总体、开发、留出及两个抽样层分别报告。定向和随机层有重叠，不能合并估计总体发生率。分母不足或同一取值的 κ 不可解释，未知不当作阴性。召回率把明确正例上的弃权计作未检出，另给可比较覆盖率。

题面是公开历史材料，无法排除预训练接触或既有研发接触。留出样本应在调整模型前固定。已看过的留出结果只可用于总结，调整后需另取未用评测题群。

## 概率准入

题级门槛使用固定留出组的正负例数、独立 κ、精确率、含弃权召回率和覆盖率。达到题级门槛之后，还需要完整、独立编码的年度变化及前瞻表现。没有变化的目标适于描述，稀疏和未达门槛的方向仅保留研究记录。现有 v3 保持按其原始定义计分。标签基准不对考生分数、用时或命题水平做认证。
