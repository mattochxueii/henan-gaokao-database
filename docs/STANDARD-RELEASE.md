
# 六科标准卷发布与红队验收

## 运行

标准卷默认采用考场版。自印练习版用 `simulate … --layout-mode practice`。同一命题任务复用一个 `--session` 凭据，卷 ID 跨修订保持一致。Codex 命题调用按宿主会话记录凭据。批量仅使用同一学科的已校验计划，各卷独立安检。

考试说明来自政策表。答案中的作文、写作、断句、默写及客观题计分采用项目统一评分模板。2027 官方阅卷细则未随项目模板发布。新版英语 PDF 需要本机 Times New Roman 字体。可用 `GAOKAO_TIMES_NEW_ROMAN` 指定合法字体文件。

科目数据新增 `math_technique`、`experiment_archetype`、`model_fingerprint`、`relative_atomic_masses` 与 `ledger_topics`。理化生数据表使用 `table.headers`、`table.rows`、可选 `table.caption`。语文篇目原词用 `<dot>`、`<wave>` 标记。英语录音正文逐行用 `M:` 或 `W:` 标记，审核后导出 `listening-tts.txt`。

新卷在送审和出版前走当前规则。历史评分卡依原版本重算。逐题读者先看最终学生 PDF，分别提交八维回执。教研另提交中等生与尖子生分块估时及把关题证据。触及估时下限、难度倒挂、熟背套路或模型撞车即退回。估时是编辑判断。答案渲染完成后再检查有理化、评分、题干泄露及术语。

## 验收

`tests/fixtures/redteam-legacy/audit.json` 保留每科原 PDF 哈希、实际安检结果、题号和对应证据。验收测试同时要求六卷全部拦截、旧评分可重放以及六卷、48 份真题和两份冻结预测与基线 Git 对象逐字节一致。文本校验遵循仓库的换行配置。

英语朗读词数采用书面可复现口径。排除 M/W 说话人标签，缩写、时间和连字符词计作一个词。旧样卷为 842 词。实验审查保留 4.2 eV 谱线误称可见的实证。紫光处在可见光边界附近，程序按 380 nm 边界核查明显紫外误称。

语文底库收录 60 篇来源可追溯的整理文本，另有 38 篇古文和宋元明清四首诗。课标附录列 72 篇。源整理本仍有待与指定教材版本逐条核对的异文，参考异文默认不参与给分。少数古文的逐句注释待补。来源与许可信号附于底库。

物理、化学图像的仪器结构、模型和量符含义仍需印刷角色核对。程序核查可读取的图中文字、坐标轴和重叠信息。自然语言题面难度、文学风格、化学实验条件或生物学因果由学科审阅复核。
