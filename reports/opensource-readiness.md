- 通过 Git bundle 在全新目录克隆，仅有 1 次根提交。Windows Python 3.13 新建 venv，从公开版依赖清单安装。检测到无加密依赖、无 API 密钥环境变量和无私有数据目录。初始化 1 卷 5 题，SQLite 与安装后的 Skill 均读到原创题完整题面。
- 本轮宿主 AI 另行设计一题双根式方程，模板调用 0、远程 API 调用 0。独立程序求出 \\(2\\pm4\\sqrt{3}\\)，并对两根做数值回验。第二位审题者只看学生 PDF 和实际渲染页面，独立推导同一解集。发布流程验证 PDF 与盲审、数学比对的哈希，随后实际查看学生卷与解析卷的公式和文本。

## 复现

在私有仓库根目录执行 `python scripts/build_public_release.py --output ../gaokao-public --zip ../gaokao-public.zip`。输入清单位于 `public-release/files.txt`，公开候选的安装教程及数据说明位于 `public-release/`。私有资料先按旧仓库的恢复文档解密，之后运行迁移脚本并用公开版 `local_data.py import` 导入到独立本地副本。
