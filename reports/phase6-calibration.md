复核日期 2026-11-09。入库规模仍为23卷、496条题目实例、487个去重主记录。保留原下载文件、全国原始分片备份和旧题库。

## 本轮证据口径

- **55条通过双重复核**。逐项核对存档 PDF/扫描页的条件、公式、选项及有关图表，再独立重解。Ⅰ卷30/145，Ⅱ卷16/145，旧全国Ⅰ卷2题，全国乙卷7题。55条均有版本绑定的14维深度分析。
- **441条未通过双重复核**。其中405条尚未完成本轮逐题核验，36条在当前参考策略下仍有版本冲突。后者包括2023全国乙卷理科整卷23条，以及旧库已有13条题面冲突。新高考Ⅰ卷仍有115条未达到双重复核，Ⅱ卷129条。
- **61条进入本轮台账**。55条可作严格参考，另有6条2023乙理修订版本，仍处于整卷隔离。原始归档不可变。资料均为已留存的第三方候选，人工与官方逐题认证各0。
- **28/28条旧 PDF 对齐异常已逐项复核**。按来源原页核查，必要时与题图或可读重绘坐标核对。低对齐分数可能来自公式占比、跨栏、表格和图像。机器对齐分数未被用作提升级别的依据。

机器结果见 [逐系列与逐年统计](phase6-calibration.json)，逐题数据在 [版本绑定台账](../national/research/calibration.jsonl)。原页哈希、页码和原题版本都保留。严格查询以当前有效版本为准。

## 实际修订

- 2024Ⅰ12恢复填空格式，移出原页未印的整理辅助图。Ⅰ13将切点限定在第一条曲线上，第二条曲线通过公共切线恢复其不同的切点。Ⅰ14补回每轮从余牌随机取牌、比较与弃置的条件。三个生效题面使用新版本哈希，旧解析未作为新版本答案继承。
- 2022乙文10核对题面、选项和解析。正确公比为1/2，第三方解析误写1/3并与自己的末项结论冲突。题面版本相同，生效解析替换为独立重解，原答案文件继续留档。
- 2024Ⅰ19完成三问重解，第三问补全了反余数类删对的奇偶构造。原整理解析只有该类删对可分的结论，台账写出了两种构造和严格概率下界。
- 2023乙理1、2、5、13、14、16分别更正复数分母/共轭与选项、集合设问、圆环及选项、根号、遗漏线性约束、指数。新答案只绑定修订版本。1、2、5另核对公开二次整理来源。其余17条未建立可接续的新版本，23条继续禁止作命题依据。
- 图表核对包括2022Ⅱ19、2023Ⅱ19、2026Ⅱ15的分组边界和柱高，旧卷流程图的初值、更新次序、退出阈值，以及2022Ⅰ19、2024Ⅰ17和2024Ⅱ17中的点线关系。2026Ⅱ15的上游子问为扁平列表，嵌套标号以 PDF 原页为准。

## 去重与使用边界

按完整条件和题图核查已存主记录关系。数据中9组共享主记录保持不变，18份卷各关联多个地区。补记3组已证语义同题关系，涉及2020Ⅰ11/Ⅱ12、2020Ⅰ13/Ⅱ14、2022乙文7/乙理6。前两组存在转写格式差别，后一组重绘图字节不同但流程和选项一致。研究参考包按这些版本绑定关系去重，存档主 ID 与题号保持稳定。跨年份近似候选只列筛查信号，近似分数不作合并依据。

校准数据在私有仓库保留；开源快照只同步通用代码、测试和规范。未达到严格复核的旧候选仍可按证据状态检索，`--verified-only` 排除它们。运行以下命令复现。

```sh
python scripts/audit_math_calibration.py --output reports/phase6-calibration.json
python scripts/national_cli.py reference-pack --topic 数列 --verified-only
python scripts/national_cli.py sqlite-query --year 2024 --series cn-new-gaokao-1 --number 13
```
