# 下一阶段接入建议

1. 将仓库作为只读数据源。先读取 `metadata/papers` 确认年份、卷型和河南适用性，再按题号读取 `questions`，通过资料登记定位到原卷、答案或图像。接口返回试卷 ID、题号 ID、来源、文件哈希、原页定位和审核状态。
2. 接入前定义用途权限。将只允许本地研究、可上传模型服务、可公开输出等权限分别审核。题干读取至少要求文件允许相关用途且题目已人工核验。仅有题号索引时，分析范围限于题型和分值等已记录结构。
3. 以题号 ID 与来源版本做关联，在独立目录保存知识点、能力、难度和命题意图的标注。记录模型版本、证据、分析方法、置信度、人工复核和标注规范版本。
4. 真题结构分析、原创命题、独立解答、评分验证各自留审计记录。原创试卷使用独立命名空间和输出目录。对相似题使用可复查的差异证据，对含图题、数学公式和评分规则分别检查。
5. 数据扩大后可从主档重建 SQLite 索引，建议为年份、学科、地区和原始题号建立索引。SQLite 只做派生查询层，JSON/JSONL 继续保存原始登记。
