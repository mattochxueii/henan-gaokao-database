# 第二阶段交付与验收

交付复核日期为2026-11-08。项目继续使用原有私有仓库，开发分支为phase2-math-skill-prototype。

## 已形成的工程

现有38道数学候选题面、原PDF与页图均保留，新增仓库内相对路径读取、认证加密分片备份和恢复机制。63个分片覆盖23个原有文件，整份密文为3969444字节。恢复密钥独立交付，Git与项目ZIP均不含密钥或解密原文。

逐题分析有38条，包含主要与次要知识点、模块、核心素养、思路、逻辑、条件设计、计算量、综合程度、障碍、难度依据、创新判断及另一真实候选题的版本绑定比较。每条关联题面校验值、源文件校验值、页码、解答版本、分析修订号。宿主未提供可核实的精确模型标识，字段如实记录not_exposed_by_host。

命题规则库区分官方要求、候选直接事实、两样本观察、未验证假设和模拟设定。按实际题面作出的统计见analysis/paper-patterns.json及reports/paper-patterns.md。两年同为19题150分，2027模拟沿用该历史结构，题型及分值在蓝图中检查。设计难度采用1级4题、2级6题、3级5题、4级3题、5级1题，属于本原型设定。

## 数学候选审核

38题均检查题号顺序、题干、选项、分值、子问、公式字段、页码、图表位置和源文件。主候选为2025锦宏回忆重排版与2026第三方扫描候选。页图以AI视觉方式对照，教师人工核验与命题机构确认均仍为0。当前已核的是候选内容和来源关联。

原有questions索引、独立解答及来源记录保留。当前版本的答案与修订推导存于analysis/curation.jsonl，查询同时提供历史解答和current_solution，防止不同选项顺序或数学条件混用。

对指定的10道重点题实际运行独立程序复算。它们覆盖2025第4、6、9、11、15题及2026第9、12、13、17、18题。部分程序检查只覆盖关键计算或性质，完整证明仍需推理复核。所有结果带当前候选校验值，见reports/original-math-checks.json。

2026第9题分母、第12题系数和第18题点名有可视原始候选差异。第13题两图第一空均θ，第17题两图均15分，二手摘要错误已定位。2025第15题原表的0.005/3.841配对按原图保留并标注，实际使用的0.001列不受影响。详细异文及证据等级见reports/phase2-conflicts.md。

## 可运行Skill与四组实验

skills/henan-math使用标准SKILL.md、便携启动脚本和相对数据库配置。已在项目.agents目录安装并实际调用，源码也提供独立安装包。

本原型由宿主AI完成研究、题目族设计和文字推理复核，运行时按种子采样。26个受支持题目族覆盖高中常见模块，数学提案、独立求解、审题、蓝图、输出分为模块。独立求解函数只接收族与参数，无法读取草稿答案，结果经SymPy或独立枚举重新计算。

四组实验实际运行并保存36道新题。数列5题按设计等级1至5递进，导数5题重推理与综合，50分综合卷7题，150分模拟卷19题。每组均提供题卷、答案解析PDF、可编辑Markdown、run.json和逐次尝试记录。程序可核部分与需要文字全域证明的部分分别标记。实际数量和状态汇总见reports/experiment-summary.json。

远程模型API调用数为0，代码不含API密钥。当前生成范围限定于已编写独立求解器的题目族。新增自由题面的任意语义验证尚未实现，需要扩展规范、求解器及回归测试。题目族与当前38个候选的条件结构不同，文本门槛也会比较同卷重复。此范围内的比较尚不能证明全球首次出现。

## 真实验收流程

已实际运行以下入口。数列研究返回4题，分别为2025第13、16题与2026第7、14题，依据为完整候选题面。它们分别体现等比块和、递推与导数综合、等差配对构造、局部等比存在性。

~~~powershell
python scripts/math_skill.py research --topic 数列
python scripts/math_skill.py rules
python scripts/math_skill.py generate --mode sequence --seed 20261107 --output <新目录>
python scripts/math_skill.py verify <新目录>/run.json
~~~

独立前向测试复算了5道数列题，并检查细知识点“等比数列”的生成入口。首轮发现解析使用未说明的内部参数、交错递推缺中间变换，均已修复并复测。见reports/skill-forward-test.json及reports/skill-forward-retest.json。

2025第1题与2026第17题也已通过现有查询入口实际读取完整候选内容、选项或子问、来源页码及对应版本答案。脱敏查询证据见reports/retrieval-evidence.json，完整结果在本机.private下保存，恢复后可直接重跑。

## 持久化、测试与文件检查

全新目录中用独立解释器恢复分片，无网络下载，恢复23文件并查询38题。接着重新安装Skill、检索4道数列候选、生成并验证5道新题。修改一张页图后，校验会识别变化。依赖从本次已安装的副本复制，换电脑可按requirements.txt重新安装，未将临时绝对路径作为数据入口。

自动测试覆盖原有目录程序、题面分析绑定、版本答案、所有题目族多种种子、四种题型、无解多解、错误答案、重复选项、条件修改、重复度、试卷结构、加密恢复、路径越界、并发备份及PDF输出。最终实际执行结果见reports/test-results.json和test-results.txt。

8份PDF共27页，使用Poppler逐页渲染，检查公式、上下标、选项、图像、分页和页码。初次检查发现Unicode上下标缺失与空白尾页，已改成显式上下标排版并消除尾页。PDF字节校验和最终视觉审核记录见reports/pdf-qa.json。

完整模拟初次触发相似度门槛，实际原因是旧检测器删除过多公式却保留通用作答提示。失败与三次重试记录保存在reports/rejected-full-run.json。修正归一化后重新生成、求解和检查。备份写入的Windows兼容问题也通过测试发现并修正，原有备份与原文保持可恢复。

GitHub连接单次上传整份密文时，自动审批因输入超过审查容量而未执行。工程改为可逐片审核和校验的备份分片，各分片通过正常连接上传。

## 交付边界和待补材料

- 两年仍缺命题机构认证的考场原卷、正式评分参考及明确覆盖相应使用方式的权利凭证。候选身份与官方身份继续分开记录。
- 2025若干异文的另一来源仅保留网页文字记录，缺同等级原始图证。2026已存在实物差异的版本也需认证原卷裁决。
- 难度、创新程度和高考风格为基于有限样本的AI判断。教师盲评、考生作答数据、广泛外部题库去重与完整课程标准逐条映射尚待开展。
- 文字证明有AI独立推理复核，程序验证范围按题目保存。任意自然语言证明的完整形式化验证仍有缺口。
- 本环境未找到LibreOffice，未交付未经渲染核验的Word。可编辑源为Markdown与结构化JSON。
- 原型的远程模型接入暂未启用。宿主AI可通过Skill编排研究与设计，受支持的题目族可直接运行。

以上状态在README、题目记录、答案册和规则中保持一致。待补材料可放入private-data/intake/<year>/math，再按README的import-file流程登记。GitHub审核以独立分支的PR为准。
