# 全国历史数学研究与目标省份AI题面写作

标准模拟和专项训练直接使用既有蓝图及题位门槛。只有用户明确要求概率预测研究时才读取 [冻结预测与三种模式](references/forecast.md)。概率研究的未来结果评分与原创题质量独立。

使用时告知正在应用 henan-math。先读取实际题库和分析，再创作。现有候选、模板换参或历史JSON重放不能称为一次新的AI原创。

## 定位与研究

运行 scripts/run.py。支持 --database、HENAN_MATH_DB 及相对安装配置。研究前阅读 [national.md](references/national.md)，按年份范围、省份、学科、系列、知识点、题型、难度、思想方法和能力检索。先读取目标制度和当前规则，再构建分层、每卷限额的完整参考包。查看 database.json 确认版本。公开版直接使用原创样本和用户合法导入的题目，私有存档版可另行恢复历史资料。见 [storage.md](references/storage.md)。

研究必须关联题目ID、版本、来源页及证据。公开版的历史来源目录只提供线索，研究结论以实际查询到的完整题面为依据。私有存档版的38份分析基于2025/2026第三方候选，如存在 analysis/review-overrides.json 则读取哈希绑定更正层。官方要求、候选事实、有限样本观察与模拟设定分开。2027卷型尚未确认。

要求基于已校准真题、专项试验或整卷质量对照时，先读 [校准与专项协议](references/calibration.md)。严格模式绑定经原页复核及独立重解的版本，并记录可借鉴的推理机制、原创结构差别和独立质量审核。

研究某知识点或准备专项训练时，先报告对应年份与知识点的实际严格检索数，再按该范围设计题目。全卷模拟沿用目标蓝图与整卷门槛。需要独立留出对照时，在创作前冻结分组并仅打开参考包，参见 [留出对照协议](references/evaluation.md)。

## 三层命题

必须阅读 [writing-protocol.md](references/writing-protocol.md) 和数据库 analysis/language-rules.json。依次完成：

1. 动态规划知识覆盖、推理层次和关联子问，AI自行创作 math_spec，保留原始版本、真实模型身份（不可得则 not_exposed_by_host）、条件结构及拒绝修订。
2. 通过 writing-request 生成不带答案/设计提示的独立写作请求。AI用规范中文组织条件和设问，用公式注册表输出常见高中记号，再 attach-writing。不得将程序内部任务直接印成试卷。
3. 先独立数学核查，再排版 student-text，得到 review-only PDF 和页图。无法规范转换的公式、缺条件、未定义符号、提示、无依据高分均退回修订。

候选格式见 [写作协议](references/writing-protocol.md)。历史 v1 见 [ai-protocol.md](references/ai-protocol.md)，出版流程使用 v2。输出到新目录，保留失败记录和修订依据。

## 先样卷再整卷

先用5题不同题型生成 pilot，由独立审题者只看最终PDF与实际渲染图，不读JSON、答案、设计和源码。逐页实际查看，逐题独立求解、检查条件、中文、记号、分值与整卷风格。保存真哈希和完整推理，不以程序成功代替考生体验。

执行 publish 需同时提供匹配PDF的 --student-review 与 --math-comparison。所有题及整卷均须通过；数学比对含程序结果和独立PDF解答。发布复制同一PDF字节，修订后旧审核作废。未审题稿只称审阅草稿。

通用 full 传 --pilot-certificate <已发布5题目录>/publication.json。已校准研究模式使用三个专项的发布证书。目标配置的8单选、3多选、3填空、5解答及150分是模拟依据，难度另行评估。

新版整卷在 `coverage_plan` 记录主模块分布依据、梯度与取舍。主模块占分达到四分之一，或跨三种题型出现时，说明这些题各自的推理机制。该阈值用于触发复查，保留真实的综合题与模块权重差异。

整卷出题前读取 [题位与结构复核](references/paper-position.md)，先取得五题题位样卷证书。题位功能、独立解题链、模块覆盖、结构重合及用时区间分别检查。修改卷面后复核对应 PDF 页面。

## 独立数学验证

求解进程只接收 math_spec，不接收命题者答案或思路。处理定义域、根集、边界、唯一性、选项、图形条件和递推。检查不支持的部分保持 complete=false，不能默认正确。无穷项证明、轨迹充分性和一般参数分类另由PDF独立推理完成。

看 `program_coverage.status` 区分完整规格检查、部分符号支持和仅独立推理。`program_checks_passed` 仅说明已运行的检查无错误。未完整覆盖的论证须逐项检查必要性、充分性、边界、等号、适用范围和高中解法。独立AI审查、形式化证明和教师核验分别登记。干扰项保留具体错误路径，实际误选频率须来自作答。

估计难度须有知识、读题、建模、推理、运算、综合、突破口、时间及来源层次依据。不能将简单求导/代入赋予高分。主观估时与实际考生统计分开。

## 输出与验收

输出题目、正常中文高中解法、题目分析及质量报告。答案PDF另做独立校审，实际查看公式、图、分页与答题区域。公开版的原创样卷和解析位于 examples/pilot。私有存档版历史实验及逐题证据位于 experiments。

有评分细则的整卷设置 `paper.require_scoring`。在数学对照中提交绑定卷面哈希的 `scoring`，标记 `authority: project`。评分点对应具体等式、分类、证明或结论，检查题目总分及各问分值。旧卷可用 `solution-edition` 生成单独的答案与评分版本。

验收请求须真实研究→新AI创作→独立写作→数学检查→PDF盲审→数学比对→publish。重放历史证据只称复现。高考风格相似性是有来源、有限样本的编辑判断，不声称全网原创、高考等难或经验验证。

## 模型与备用模式

默认使用当前宿主AI写候选文件，无需购买API。若用户已有环境密钥，可使用 --engine ai --model <显式模型>，调用/重试/上下文受预算限制，密钥不写文件。API输出仍须遵守v2写作和PDF审查，不能绕过发布检查。

AI不可用就如实报告；只在显式 --allow-template-fallback 时回退。备用练习使用：

```powershell
python <技能目录>/scripts/run.py generate --engine template --mode full --output <新目录>
```

26族模板只称参数化练习。不得假称动态AI。安装及完整命令见仓库README和写作协议。
