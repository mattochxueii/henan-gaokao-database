# 贡献指南

提交前运行 `python -m unittest discover -s tests -v`。修改数据时保留试卷身份、题目主 ID、试卷实例 ID、来源、分值和版本关联。对候选题面、考务事实、独立解答和模拟设定分别标记。

对转载许可不明的资料，只提交来源和自写摘要。获得明确授权后，记录权利人、允许分发的内容范围、授权文本和出处。原卷、全量题面、扫描图、第三方答案、私有备份、密钥及含完整题面的日志应留在受控目录。自创题应记录生成方式、独立验证范围与质量审查状态。

新增学科时先扩充数据校验和检索测试。对英语部分、理综子卷、各省选考卷和数学文理卷使用独立身份。自动化测试采用原创或合成的样本。

维护者应从受审查的文件清单构建新快照，再从空目录验证安装和测试。公开仓库的历史从审查过的干净快照起步。
